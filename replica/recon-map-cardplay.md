# Recon Map: Card Play Scene Overhaul (Ref: Disney Solitaire)

(사용자가 전달한 리콘 맵 — 2026-10-18 저장. 메타 게임(수사 보드 · 논리 그리드)은 범위 밖)

## 흐름
- F01: 입장(입장료) → 플레이(콤보) → 클리어(골드 · 단서). 틀린 카드: 흔들림 (우리는 콤보 유지).
- F02: 덱 소진 → +5장 구매 → 계속 (원작 가격 500G는 리콘 문서 기재값, 직접 확인 안 됨).

## 원작에서 가져오지 않는 것
- 디즈니 IP(캐릭터 · 음악), 요정 가루 연출 → 돋보기 · 타자기 · 미스터리 연출로 대체.
- 조작 의심을 받는 RNG → 우리 클리어 보장 생성기 유지.
- 참고: '장애물 카드(자물쇠 · 얼음 · 덩굴)'는 리콘 문서에서도 "이런 류 게임에서 흔한" 추정으로 적혀 있음 (원작 화면에서 직접 확인한 근거 아님).
